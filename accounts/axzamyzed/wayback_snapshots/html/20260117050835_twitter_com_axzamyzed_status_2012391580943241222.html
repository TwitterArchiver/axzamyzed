Good morning, everyone! After a few weeks of development, hrt-tracker-cloud (cloud-sync version) is now available as a test release 🎉

Deployment
•Backend: hosted in Los Angeles, California (USA)
•Frontend: hosted on Cloudflare Workers

Key Features
1.Multi-device cloud sync: After logging in, your data automatically syncs across all your devices. When changes occur, they’ll sync to every logged-in device in up to ~5 seconds. You can also view and manage your logged-in devices at any time.
https://t.co/RdMYdidbrV sharing: You can create shareable copies of your data—or even enable real-time sharing (available only for unencrypted users).
https://t.co/aZBKr4I66q security: Your data is stored securely on the server. If you set a security passcode, your data will be encrypted and protected. Without both your login password and security passcode, no one can access your data.
4.Backup strategy: The server backs up data to Cloudflare R2 every 8 hours and keeps the most recent 20 backups to reduce the risk of accidents or data loss.
5.PWA icon support: When installed as a PWA app, it now displays an app icon (see the example image).

For now, this feature is being rolled out experimentally only at the deployment locations listed above. To try it out, please visit:
https://t.co/bgkJOaARgF

⸻

Feedback & Support

We know that for a project to grow long-term, ongoing communication with users is essential. If you run into any issues, feel free to reply in this thread or DM me directly.

However, for security reasons, we did not build any backend admin tools (unless we inspect the database directly, we can’t even tell how many users are in the system). Because of that, we’re unable to handle requests including—but not limited to—forgotten passwords or account recovery. Sorry for the inconvenience, and please make sure to keep your passwords in a safe place.

Due to personal constraints, I used Codex Cloud to help fix some bugs. Because of time limits, I haven’t completed a line-by-line review of that portion of the code yet. I’ll complete the review process as soon as I’m able to. That said, I want to state clearly: the current version’s usability and security are within a controlled and assured range.

I can also promise that cloud sync will be free during this stage. If we ever need to introduce paid plans in the future due to operating costs, we’ll announce it at least one month in advance, and we’ll do our best to keep pricing very low.

Thanks for taking the time to read this. Wishing you all the best, and I hope you have a smooth experience!
Sincerely,
