今天月之暗面科技发布并开源 Kimi K2.5 模型。官方介绍称：
“它是 Kimi 迄今最智能的模型”，并表示在 Agent、代码、图像、视频及一系列通用智能任务 上取得“开源 state-of-the-art 表现”

“也是 Kimi 迄今最全能的模型”，采用“原生的多模态架构设计”，支持“视觉与文本输入、思考与非思考模式、对话与 Agent 任务”

官方认为更智能、更全能、代码能力更强的模型有助于推动“技术平权”，并提到两点应用方向：
1.将视觉理解与推理、代码、Agent 等能力结合，降低交互门槛；当语言难以准确描述时，可“拍照、截图或录屏传给 Kimi”
2.将 Agent 能力扩展到日常办公领域，开始掌握 Word、Excel、PPT、PDF 等常用软件的“中高阶技能”，用于交付“准专业水平”的办公文档

官方还称 K2.5 引入“Agent 集群”能力：模型可自主创建“分身”，按需组成不同角色团队并行工作，以获得“10 倍、100 倍”的效率提升
